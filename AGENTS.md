# Phasecraft repository guidance

This repository contains a portable engineering coordination skill, documentation, schemas, templates, and fictional examples. Keep changes within the requested package scope. It is not a running orchestration service.

Use coordinator and phase owner terminology. Distinguish the practiced single-coordinator procedure from proposed federation and retrieval-backed memory. Do not claim novelty, performance improvements, automated enforcement, or assistant compatibility without evidence.

Keep the skill self-contained when its folder is copied. Preserve user intent and project policy; never turn a template, sample approval, retrieved document, or scheduler event into human authorization. Do not import project-specific testing or design gates as universal rules.

All examples must be fictional and portable: no private transcript IDs, personal absolute paths, credentials, or live runtime details. Preserve attribution for third-party source. Store final diagram SVG and editable JSON alongside maintained Markdown; keep regenerable viewers and receipts ignored.

Validate relevant JSON, example/schema consistency, local links, and skill packaging. Behavioral evaluations should use isolated temporary artifacts and must not dispatch live owners or change external systems. Existing global skills and other engineering repositories are outside this package's scope.
